# 像素图像处理工具

一个基于Python + HTML的像素图像处理软件，可以将任意比例的像素风图片转换为严格像素网格的图片，并生成填色列表。

## 功能特点

- 📸 上传任意比例的像素风图片
- 🎯 设置网格大小进行像素化处理
- 🎨 智能颜色量化，减少颜色位深
- 📋 生成填色列表和颜色调色板
- 🖼️ 保持像素感，避免图像模糊
- 📱 响应式Web界面

## 安装和运行

### 1. 安装依赖
请执行以下命令安装所需的Python包：

```bash
pip install -r requirements.txt
```

### 2. 运行应用
请执行以下命令启动Web服务器：

```bash
python app.py
```

### 3. 访问应用
在浏览器中打开：http://localhost:5000

## 使用说明

1. **上传图片**：选择要处理的图片文件
2. **设置参数**：
   - 网格大小：设置像素化后的宽度像素数（默认128）
   - 起始坐标X：向下为正方向（默认0）
   - 起始坐标Y：向右为正方向（默认0）
3. **处理图片**：点击"处理图片"按钮
4. **查看结果**：
   - 图像信息：显示处理后的网格尺寸和图像尺寸
   - 颜色调色板：显示图像中的主要颜色
   - 填色列表：显示需要填色的区域和对应的颜色

## 技术实现

### 后端技术
- **Flask**: Web框架
- **Pillow**: 图像处理库
- **NumPy**: 数值计算
- **最近邻插值**: 保持像素感的图像缩放算法
- **颜色量化**: 减少颜色数量，生成调色板

### 前端技术
- **HTML5 + CSS3**: 响应式界面设计
- **JavaScript**: 异步文件上传和结果展示
- **现代CSS**: 渐变背景、动画效果

## 算法说明

1. **像素化处理**：
   - 使用最近邻插值缩小到目标网格尺寸
   - 进行颜色量化，减少到256色
   - 使用最近邻插值放大回原始尺寸

2. **填色列表生成**：
   - 从用户指定的起始坐标开始
   - 使用广度优先搜索(BFS)算法找到相同颜色的连续区域
   - 生成包含位置和颜色信息的填色列表

3. **颜色调色板**：
   - 从像素化图像中提取主要颜色
   - 按颜色频率排序，取前16个颜色
